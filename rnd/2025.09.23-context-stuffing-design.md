# Context Window Stuffing Experiment Design - 2025.09.23

## Overview

This document outlines the design and implementation of a CLI experiment for extracting text from large PDFs and using Gemini 2.5 Flash to generate image descriptions and OCR, creating compressed text representations suitable for context window optimization in Gemini Live.

## Problem Statement

Large PDF documents (1MB-20MB) cannot be directly processed by LLMs due to context window limitations. Traditional text extraction loses critical visual information from diagrams, charts, and images. This experiment explores whether AI-powered image analysis can create comprehensive text representations that preserve essential visual information while achieving significant size reduction.

## Objectives

1. **Context Window Optimization**: Reduce PDF file sizes by 90%+ while preserving information
2. **Visual Information Preservation**: Convert images to descriptive text using Gemini 2.5 Flash
3. **Text Quality**: Maintain readability and structure in extracted content
4. **Cost Efficiency**: Demonstrate cost-effective processing for production use
5. **Performance Analysis**: Measure compression ratios, processing times, and API costs

## Technical Architecture

### Core Components

1. **Authentication System** (`auth_checker.py`)
   - Automatic GCP credential validation on every command
   - No manual authentication steps required
   - Clear error messages with remediation instructions

2. **PDF Processor** (`pdf_processor.py`)
   - Page-by-page text extraction using PyMuPDF
   - Image extraction with position and size metadata
   - Integration with Gemini client for image analysis

3. **Gemini Client** (`gemini_client.py`)
   - Uses latest Gemini 2.5 Flash model with thinking capabilities
   - Dual functionality: image descriptions and OCR text extraction
   - Rate limiting and error handling
   - Token usage tracking

4. **Output Formatter** (`output_formatter.py`)
   - Rich terminal tables with compression metrics
   - Structured JSON reports for programmatic access
   - Well-formatted markdown files for human consumption

5. **Metrics Analyzer** (`metrics.py`)
   - Compression ratio calculations
   - Performance analysis and bottleneck identification
   - Cost estimation and optimization recommendations

6. **CLI Interface** (`reduce_to_text.py`)
   - Click-based command structure
   - Automatic credential checking built into every command
   - Progress tracking and error handling

### Data Flow

```
PDF Input → Text Extraction → Image Extraction → Gemini Processing → Markdown Generation → Metrics Calculation → Output
```

1. **Input**: PDF files from `data/input/` directory
2. **Processing**: Page-by-page extraction and AI analysis
3. **Output**: Markdown files, JSON metrics, terminal reports

## Model Selection: Gemini 2.5 Flash

### Why Gemini 2.5 Flash?

- **Latest Model**: Most advanced version with thinking capabilities
- **Multimodal**: Optimized for both text and image processing
- **Cost Effective**: Better price/performance than previous versions
- **OCR Quality**: Superior text extraction from images
- **Description Quality**: Detailed, contextual image descriptions

### Prompt Engineering

**Image Description Prompt**:
```
Analyze this image and provide a detailed description that would be useful for someone who cannot see the image. Focus on:

1. Text content: Any visible text, labels, titles, captions
2. Document structure: Headers, sections, layout elements
3. Visual elements: Charts, diagrams, graphs, tables
4. Context: What type of document/content this appears to be
5. Key information: Most important data or concepts shown

Be concise but comprehensive. This description will be used for text-based AI processing.
```

**OCR Extraction Prompt**:
```
Extract ALL visible text from this image. Preserve the original structure and formatting as much as possible.

Guidelines:
- Include headers, body text, captions, labels
- Maintain line breaks and paragraph structure
- If text is in tables, preserve table structure
- Include any numbers, dates, or special characters
- If text is unclear or partially obscured, indicate with [unclear] or [partial]

Return only the extracted text, no additional commentary.
```

## Risk Assessment

### Technical Risks

1. **API Rate Limits**: Mitigated by built-in rate limiting
2. **Large Image Processing**: Mitigated by automatic image resizing

1. **High Token Usage**: Image optimization reduces token consumption
2. **API Pricing Changes**: Current pricing estimates documented

### Quality Risks

1. **OCR Accuracy**: Gemini 2.5 Flash provides superior OCR quality
2. **Description Relevance**: Carefully crafted prompts ensure context
3. **Information Loss**: Multiple extraction methods (text + images)
